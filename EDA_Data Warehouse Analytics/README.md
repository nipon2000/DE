# EDA Data Warehouse Analytics

## Project Overview
This project performs SQL-based exploratory data analysis on a data warehouse dataset using Databricks notebooks.  
The analysis focuses on customers, products and sales data to understand business performance, customer behavior, product trends and sales patterns.

## Tools Used
- Databricks
- SQL
  
## Dataset
The project uses a star-schema style dataset with:

- dim_customers.csv — customer dimension table
- dim_products.csv — product dimension table
- fact_sales.csv — sales fact table

The data is stored in the `data/` folder.
