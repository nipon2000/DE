# SQL Data Warehouse Analytics

## Project Overview

This project performs SQL-based exploratory data analysis on a data warehouse-style dataset using Databricks.

The analysis focuses on customer, product, and sales data to understand business performance, customer behavior, product trends, revenue patterns and key analytical metrics.

The project follows a structured analytics workflow using dimension and fact tables, similar to a star schema model.

## Tools Used

- Databricks
- SQL
- Delta Tables
- GitHub

## Dataset

The project uses three main tables:

- `dim_customers.csv` — customer dimension table
- `dim_products.csv` — product dimension table
- `fact_sales.csv` — sales fact table

The dataset is stored in the `data_files/` folder.
